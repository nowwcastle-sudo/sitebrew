# 국가법령정보센터 Open API — 법정 페이지 검토용 (J13)

> 2026-09-29 실측. 운영자 지시: 「법령정보센터 키는 지금 아는 게 중요한 게 아니라, 앞으로 구축 완료되고 실제로 쓸 때 아는 게 중요한 거야」.
> 이 문서는 **P3-3 법률 검토 단계를 만들 사람과 실제로 돌리는 법률 에이전트**가 읽는다.
> 코드 쪽 정본은 P3-3에서 만드는 `factory/legal/law-api.mjs`이고, 실행 전 점검은 `factory/doctor.mjs`(J14)가 맡는다.

## 키

- 이름: 환경 변수 **`LAW_API_OC`**.
  - OC는 신청자 ID다. 발급은 open.law.go.kr에서 Open API를 신청해 받는다.
  - 값은 로그·보고서·대화에 **출력하지 않는다**. 존재와 길이만 확인한다.
- 읽는 곳: 프로세스 환경이다. 키를 넣은 뒤에는 새 셸을 연다.
  - Windows 사용자 환경 대체 읽기는 `FACTORY_USER_ENV=1` 일 때만 켜진다(공개판은 기본 꺼짐). 켜면 그 프로세스 안으로만 읽는다.
  - `factory/media/fetch-pexels.mjs`의 `PEXELS_API_KEY` 읽기와 같은 방식이다.
- 오류 메시지에 요청 URL을 넣을 때는 `OC=` 값을 `***`로 가린다.

## 엔드포인트 (2026-09-29 실측, HTTPS, 응답 JSON)

| 용도 | 요청 | 확인한 결과 |
|---|---|---|
| 법령 검색 | `https://www.law.go.kr/DRF/lawSearch.do?OC=<키>&target=law&type=JSON&query=<법령명>` | HTTP 200. `LawSearch.totalCnt` = 2(「개인정보 보호법」·같은 법 시행령). 항목 필드 `법령명한글`·`법령ID`(011357)·`법령일련번호`(MST 283839)·`시행일자`(20260911) |
| 조문 하나 | `https://www.law.go.kr/DRF/lawService.do?OC=<키>&target=law&MST=<법령일련번호>&type=JSON&JO=<조 6자리>` | HTTP 200, 5.7KB. 최상위 `법령` → `법령키`·`기본정보`·`조문.조문단위`. `JO=002200`이 제22조 「동의를 받는 방법」을 돌려줬다. 조 번호 6자리 = 조 4자리 + 가지 조 2자리(제22조의2 → `002202`) |
| 사람용 인용 주소 | `https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=<법령일련번호>` | HTTP 200, 제목 「법령 > 본문 > 개인정보 보호법」. `review.json`의 `basis[].url`에는 이 형식을 쓴다 |
| 사람용 짧은 주소(보조) | `https://www.law.go.kr/법령/<법령명 붙여쓰기>/제<N>조` | HTTP 200(이동 페이지). 화면 표시용으로만 쓴다 |

**MST(법령일련번호)는 개정마다 바뀐다.** 검토할 때마다 먼저 검색으로 **현행** MST를 얻고, 그 MST로 조문을 가져온다. 캐시한 MST를 그대로 쓰지 않는다. `review.json`의 `basis[]`에는 `law`·`article`·`url`·`mst`·`effectiveDate`(시행일자)·`fetchedAt`을 남긴다.

## 검토에 쓰는 법 (한국어 사이트 기본 목록 — 원형별로 더한다)

- 개인정보 보호법 · 시행령 — 수집 항목·동의(제22조)·국외 이전·처리방침 기재 사항
- 전자상거래 등에서의 소비자보호에 관한 법률 — 청약철회·표시 의무·다크패턴(개정 조항)
- 약관의 규제에 관한 법률 — 불공정 약관
- 정보통신망 이용촉진 및 정보보호 등에 관한 법률 — 광고성 정보 전송 동의
- 위치정보·청소년 관련 법 — 해당 기능이 있을 때만

영어 사이트(GDPR·CCPA·Paddle 판매 대행 조건)는 이 API 대상이 아니다. 법률 에이전트는 각 규정의 1차 출처(EUR-Lex, 캘리포니아 주 법령, Paddle 공식 약관)를 가져와 같은 `basis[]` 모양으로 남긴다.

## 실패할 때 (조용한 실패 금지)

| 상황 | 동작 |
|---|---|
| 키가 없음 | `doctor`와 `legal-gate`가 종료 1이고, 「도구 실패: LAW_API_OC 없음 — open.law.go.kr에서 발급해 환경 변수 LAW_API_OC로 넣는다」를 낸다. 공개하지 않는다 |
| HTTP 오류·시간 초과·빈 결과 | 두 번 다시 시도한다(간격 5초·20초). 그래도 실패하면 그 조항은 `unverified`가 되고 `legal-gate`는 1이다 |
| 검색 결과에 현행본이 없음(폐지·명칭 변경) | 그 법은 `unverified`로 두고 사유를 남긴다. 옛 MST로 대신하지 않는다 |
| 응답 모양이 바뀜(최상위 `법령`·`LawSearch`가 없음) | 도구 실패다. `law-api.mjs` 모양 검사가 이것을 잡는다 |

## 법률 에이전트가 쓰는 플러그인 (2026-09-29 운영자가 켬)

- **`privacy-legal`**: 개인정보처리방침과 실제 처리(콘텐츠 객체의 수집 항목·어댑터의 전송처)가 어긋나는지 본다(`policy-monitor`·`reg-gap-analysis`).
- **`Legal`**: 약관·환불 조항 점검(`review-contract`·`compliance-check`·`legal-risk-assessment`).
- `commercial-legal`은 켜지 않았다. 구독 약관 검토가 부족하다고 나오면 운영자에게 켜 달라고 요청한다.
- 플러그인이 다루지 못하는 한국 법 조문 확인은 위 API로 한다. 플러그인의 결론에 조문 근거가 없으면 `unverified`다.
