## 3. 모듈 지도와 의존 방향

화살표는 import 방향이다. 순환이 없다. `*` 표시는 06 코드 열쇠 안으로 들어가는 파일이다.

```
Phase A (열쇠 밖)
  compare/proxy.mjs ──────────────┐
  compare/bridge.js (브라우저)     ├─▶ compare/serve.mjs ──▶ qa.mjs startSite, run-proc.mjs, blocker-class.mjs, cdp.mjs
  compare/page.mjs ───────────────┘            ▲
                                       direction-board/build.mjs (--serve만 호출)
  stamp/sample-facts.mjs ──▶ brief.mjs(읽기), content.mjs(읽기)         ◀── stamp.mjs, deliver.mjs
  intake/logo-candidates.mjs ──▶ cdp.mjs, node:fs
  stamp/finish-review.mjs (순수) ◀── stamp/finish-loop.mjs ◀── stamp.mjs (--finish-review)
  qa/brand-exposure.mjs ──▶ cdp.mjs           ◀── stamp/qa.mjs

Phase B (열쇠 안, 한 묶음)
  stamp/positioning.mjs*  ──▶ stamp/mood.mjs 방식(자기완결)
  stamp/material-family.mjs* (순수, head → 계열)
  stamp/visual-distance.mjs* ──▶ material-family.mjs
  stamp/directions.mjs* ──▶ positioning, visual-distance, material-family, style-presets
```

규칙:
- `compare/*` 는 `serve.mjs` 만 파일시스템·프로세스를 만진다. `proxy`·`page`·`bridge` 는 순수하거나 소켓만 쓴다.
- `sample-facts.mjs` 는 `stamp.mjs`·`deliver.mjs` 만 import 한다. `gen-pages.mjs` 는 import 하지 않는다(열쇠 안으로 끌려 들어가는 것을 막는다).
- `finish-review.mjs` 는 파일 읽기 외에 부작용이 없다. 행동 결정은 `finish-loop.mjs` 한 곳이다.
- `material-family`·`visual-distance`·`positioning` 은 서로 순환하지 않는다. 입력은 레시피 머리 객체뿐이다.

### 4.5 마감 리뷰 (T12, T13)

T11 문서 6절을 그대로 따른다. 여기서는 **리뷰 파일 문법**만 못 박는다.

```js
// finish-review.mjs (순수)
collectReviewInputs(runDir, pick) → { shots: [{ path, width, kind }], head, brief, blockers }
parseReview(md) → { round, disposition, findings: [{ id, where, problem, prescription: { kind, command?, note? } }] }
parseVerdict(md) → { round, results: [{ id, status }], regressions: string[] }
class ReviewFormatError extends Error

// finish-loop.mjs
nextStep(runDir, pick) → { action: 'review'|'apply'|'verdict'|'ask-human'|'done', round }
```

`review-<n>.md` 문법 (`references/review-format.md` 가 정본이고 파서가 이것을 읽는다):

```
# Review <n>
disposition: fix            # ship | fix | rebuild | recapture

## F1
where: hero / 375px
problem: 제목이 로고와 겹친다.
prescription: revise "히어로를 차분하게"
## F2
where: header
problem: 로고가 너무 작다.
prescription: human 로고 파일을 더 큰 해상도로 다시 주세요
```
- `disposition` 줄은 필수, 값은 4어휘뿐이다.
- 소견은 `## F<번호>` 블록이다. `where`·`problem`·`prescription` 세 줄이 모두 필수다.
- `prescription` 은 `revise "<말>"` 또는 `human <한 줄>` 이다.
- `ship` 이면 소견 블록이 0개여야 한다. 아니면 `ReviewFormatError`.

`verdict-<n>.md`:
```
# Verdict <n>
F1: resolved
F2: unresolved
regression: 모바일 푸터가 잘린다
```

`nextStep` 판정 순서는 T11 문서 6.2와 같다. `ask-human` 은 자동 경로에서는 출력만 하고 멈추지 않는다.

### 4.6 `factory/stamp` Phase B 모듈 (T19~T21)

```js
// positioning.mjs*
positioningProfile(text) → null | { tags: Tag[], prefs: { motion?: 'M0'|'M1'|'M2'|'M3'[], colorLogic?: string[], theme?: 'light'|'dark', display?: string[], family?: string[] } }
// Tag = 'frontier' | 'trusted-local' | 'simplest' | 'premium' | 'playful'
// 낱말 매칭은 mood.mjs 와 같은 방식(ko 어간 포함, en 낱말 단위). 표에 없으면 null → 효과 없음, why 에 이유.
export const POS_LIBRARY_W = 0.04, POS_PRESET_W = 0.06, POS_PALETTE_W = 0.10
positioningHits(prefs, headLike) → number   // 일치한 축 수. 층마다 상한을 호출 쪽이 적용.

// 태그 → 선호 표
// frontier       motion M2+, colorLogic K6/K7/K2, display D2/D3, theme dark
// trusted-local  motion M0/M1, colorLogic K1/K3, theme light, family editorial-warm
// simplest       motion M0/M1, colorLogic K1/K9, display D1, theme light
// premium        motion M1/M2, colorLogic K5/K1, theme dark|light 둘 다(감점 없음), display D1/D2
// playful        motion M2/M3, colorLogic K8/K2, display D3

// material-family.mjs*
materialFamily(head) → 'glass'|'collage'|'print'|'paper'|'kinetic'|'editorial'|'terminal'|'plain'
// 앞에서부터 첫 일치:
//   glass     surface C5 | texture X7/X8
//   collage   texture X3 | surface C8
//   print     texture X2 | surface C6
//   paper     texture X1/X4/X5/X6 | shadow S3
//   kinetic   display D3 | motion M3
//   editorial header H5 | display D2
//   terminal  defaultTheme dark && radius R0 && table T4|T1
//   plain     그 밖

// visual-distance.mjs*
visualDistance(a, b) → number        // 서로 다른 칸 수(정수)
// 셈하는 칸 7개: surface, header, shadow, display, texture, defaultTheme, hero. 각 1점. 값이 없으면 AXIS_DEFAULTS 로 채워 비교.
SPACE_RULE = { minDistance: 2, distinctFamily: true }
checkWorldSpread(heads) → { ok, violations: [{ pair: [idA,idB], rule: 'visual-distance'|'family-clash', detail }] }
// 위반은 directions.mjs 의 rejected 에 규칙 id(`visual-distance` · `family-clash`)로 기록한다.

colorStrategy(head) → 'Restrained'|'Committed'|'Full'
//   Restrained: K1, K3, K5, K9
//   Committed : K4, K6, K7
//   Full      : K2, K8
thesisOf({ family, strategy, goal }) → string
//   "{계열} 세계에서 {색 전략} 색으로 {포지셔닝 또는 원형 목표}를 보여 줘요."
```
`directions.mjs` 후보 머리 4칸: `{ thesis, sig, world, risk }`. `thesis` 는 위 템플릿, `sig` 는 후보의 가장 큰 차이 축 한 줄, `world` 는 계열 이름, `risk` 는 `rejected`·lint 경고에서 한 줄. 판정에 쓰지 않고 대시보드 표시용이다.
