- 사진은 `/textures/*.webp` 로 부른다. 소비자는 이 폴더를 자기 `public/textures/` 로 복사한다(shadcn registry 가 이진 파일을 못 싣는다).

## 질감별

### 1. 리소그래프 (risograph)

- 보이는 특징: 번진 입자, 잉크 두 색이 몇 px 어긋나 겹쳐 제3의 색이 생김, 거친 망점, 종이 결. 인쇄 오류가 매력이다.
- 기존 X와 겹침: **X2 변형.** 망점(X2)에 그레인(X1)을 겹치고, 어긋남(제목 두 번째 잉크)을 더한 조합이다. 값으로 쓰려면 `X2` 훅 변수 위에 「제목 그림자」 한 줄만 새로 필요하다.
- 구현: 망점은 `radial-gradient` 6px 격자를 `ring`(레시피 두 번째 잉크 토큰) 70%, 불투명도 0.75로 위쪽 44%에만 `mask-image: linear-gradient`로 깔아 본문 쪽에서 사라지게 한다. 그레인은 X1과 같은 `feTurbulence` 데이터 URI를 불투명도 0.07로 곱하기(다크는 반전 후 스크린). 어긋남은 제목 `text-shadow: .07em .05em 0 <ring 70%>`. 이미지 파일 없음. 외부 사례도 같은 방식이다(`mix-blend-mode: multiply`로 잉크 겹침, feTurbulence 그레인, 어긋남은 변수 오프셋 — Risograph.css 소개).
- 대비 위험: 망점이 본문 뒤로 내려오면 7:1이 깨진다. 외부 사례도 곱하기 블렌드가 글자 대비를 낮추는 함정을 따로 막는다(「contrast floor」). 해법: 망점 영역을 제목 띠로 한정하고 본문 구획은 평면 + 그레인만. 견본 실측 본문 p5 10.91 이상, 최저 9.82 이상(망점을 진하게 한 최종 견본 기준).
- 성능: 마스크 그라디언트와 타일 한 장이라 첫 페인트 외 비용 거의 없다. 동작 줄이기와 무관(정지).
- 금지 목록: 충돌 없음(그레인은 DESIGN 「어두운 큰 면·그라디언트 면 한 겹」 권고와 겹치므로 밝은 면에서는 0.07 이하, 한 구획에 한 번만).
- 원형·레시피: brand·portfolio·local·commerce(굿즈). dashboard·public 제외(X2 호환표 그대로). 견본에서는 r1(도면 계측) 같은 정밀한 면보다 r5·r8처럼 따뜻한 면에서 어긋남 잉크가 잘 산다.

### 2. 레터프레스 (letterpress)

- 보이는 특징: 활자가 종이에 눌려 들어간 느낌, 글자 가장자리에 잉크가 고임, 종이 섬유, 눌린 자리 주변이 살짝 어두움.
- 기존 X와 겹침: **새 값.** X1·X2는 면의 무늬이고 이것은 글자·면이 눌린 입체감이라 겹치는 값이 없다. 다음 번호(X4 가칭)를 받는다.
- 구현: 면은 `card` 색 + `inset 0 2px 6px` 그림자 + `inset 0 0 0 1px border`(들어간 종이), 종이 섬유는 가로로 길쭉한 `feTurbulence`(`baseFrequency: 0.9 0.05`) 데이터 URI를 0.07로. 글자는 **색을 바꾸지 않고** `text-shadow: 0 1px 0 <밝은 하이라이트>, 0 -1px 0 <어두운 가장자리>`(다크는 두 값을 뒤집는다). 제목에만 `feDisplacementMap` 약한 번짐(scale 1.6)을 건다. 눌림 효과 CSS 사례가 흔히 글자색을 배경보다 약간만 어둡게 두는 것이 이 질감의 대비 위험이다.
- 대비 위험: **글자색을 옅게 만드는 쪽이 흔한 구현이다.** 글자색은 레시피 `foreground` 그대로 두고 그림자만 더하면 본문 7:1이 유지된다. 실측 본문 p5 12.95 이상.
- 성능: 글자 그림자와 타일 한 장. 제목 필터는 제목에만. 정지.
- 금지 목록: 충돌 없음. 가짜 기기 틀이 아니라 종이 표현이다.
- 원형·레시피: brand·local(공방·식당·서점)·portfolio·detail. 견본에서 r5(청자 고요)가 가장 어울린다 — 여백·재질이 레시피 무드와 같다. dashboard 제외 권장(운영 화면의 데이터 면을 흐린다, X1 호환 근거와 같음).

### 3. 제록스 (xerox)

- 보이는 특징: 거친 입자, 세로 줄(드럼 자국), 먼지 점, 번진 검은 가장자리, 한 색조.
- 기존 X와 겹침: **X1 변형 + 제목 필터.** 먼지 점은 입자 질감(X1)과 같은 종류이고, 세로 줄과 제목 가장자리 거칠기가 더해진다. 독립 값으로 둘지는 대표 판단 — 가장 약한 후보다.
- 구현: 세로 줄은 `repeating-linear-gradient(90deg, … foreground 3~6%)`, 왼쪽 가장자리는 14px 어두운 띠, 먼지는 `feTurbulence`를 `feColorMatrix`로 문턱 처리(알파 = 14R − 9.6, 점만 남김)한 타일을 불투명도 0.4로. 제목은 `feDisplacementMap`(scale 2.4) 뒤에 `feComponentTransfer`(알파 이산화)로 가장자리를 딱딱하게 깎는다.
- 대비 위험: **가장 크다.** 첫 견본(먼지 점을 면 전체 0.5로)은 본문 p5 3.77~4.90, 보조 2.55~3.61이라 7:1 미달이었다(원본 값 `_scripts/results_v1.json`). 먼지 점과 줄을 위쪽 띠에서만 진하게 하고 본문 쪽으로 마스크로 지운 뒤 본문 p5 14.27 이상, 보조 8.41 이상으로 올랐다. 다만 띠와 겹치는 줄의 일부 점은 최저 5.27~6.93이라 `texture-contrast`(최저점 7:1) 기준으로는 먼지 영역을 본문 상자 바깥으로 제한해야 한다. 본문 글자에는 필터를 걸지 않는다(필터가 획을 번지게 한다).
- 성능: 제목 필터 한 곳. 문턱 처리 타일은 래스터 한 번. 정지.
- 금지 목록: 충돌 없음. DESIGN §13 「의미 없는 장식 금지」에 걸리지 않으려면 문서·자료 성격(사본, 영수증, 인디 소식지)이라는 의미가 있어야 한다.
- 원형·레시피: portfolio·brand(인디 문화). dashboard·public·saas 제외 권장. 견본에서는 r1(도면 계측)이 「도면 사본」 의미와 맞는다.

### 4. 골판지 (cardboard)

- 보이는 특징: 갈색 종이 섬유, 골판 단면의 줄(플루트), 눌린 잉크 도장.
- 기존 X와 겹침: **새 값.** X3 콜라주는 종이 조각을 겹치는 구도이고, 이것은 면 전체 결 + 단면 띠다. X5 가칭.
- 구현: 면색은 `secondary`와 `accent`를 섞고 `card`로 한 번 더 밝혀 팔레트 안에서 만든다(진짜 갈색은 레시피 색 3벌 밖이라 쓰지 않음 — 레시피 팔레트를 깨지 않기 위한 선택이며 잃는 것은 크래프트 갈색의 즉시 인식성이다). 섬유는 가로로 길쭉한 `feTurbulence`(`baseFrequency: 0.004 0.5`, 타일 640×260) 불투명도 0.09, 위쪽 16px에 `repeating-linear-gradient` 세로줄로 단면 띠, 제목은 약한 번짐 필터 + 점선 밑줄(도장 느낌).
- 대비 위험: 면이 `card`보다 어두워지면 보조(`muted-foreground`) 글자가 먼저 7:1 아래로 내려간다. 첫 견본 보조 p5 5.99~6.53(미달) → 면을 `card` 쪽으로 밝히고 섬유를 0.14→0.09로 낮춰 7.07 이상, 최저점도 7.05(r1)로 7 위다.
- 성능: 타일 한 장 + 그라디언트. 정지.
- 금지 목록: 충돌 없음.
- 원형·레시피: commerce(포장·소품)·local·brand. dashboard·public 제외 권장. r8(솔숲 저녁)처럼 낮은 채도의 따뜻한 레시피에 어울린다.

### 5. 간유리 (frosted glass) — 조건부

- 보이는 특징: 뒤의 색·모양이 흐려져 비치는 반투명 면, 얇은 밝은 테두리.
- 기존 X와 겹침: **X 값이 아니다.** X는 면 안쪽 무늬이고 간유리는 면 자체의 처리라 C5(글래스)·오버레이(dialog·sheet·drawer) 영역이다. C5는 이미 「흐르는 카드는 불투명 + 글래스 결, 블러는 오버레이 배경 20px 상한」으로 구현돼 있다(`axes/surface/c5-glass.css`).
- 금지 목록 충돌: **있다.** `styles.json`에서 glassmorphism·liquid-glass는 `ban`이다(DESIGN §13 표 「모든 내비·모달에 글래스모피즘 블러 → 블러는 의도가 있는 한 곳만」, kill-ai-slop #19, DESIGN §6 MUST 「backdrop-filter는 고정·스티키 요소와 모달 배경에만」, `prefers-reduced-transparency` 대체 MUST). 그래서 이 질감을 허용한다면 아래 조건을 모두 채울 때뿐이다.
  1. 의도가 있는 한 곳(화면당 하나). 내비·모달 전부에 걸지 않는다.
  2. `backdrop-filter`는 고정·스티키·오버레이에만. 스크롤되는 카드·큰 면에는 걸지 않고, 그 자리는 C5처럼 불투명 + 안쪽 테두리 결로 「간유리 느낌」만 낸다.
  3. 글자가 올라가는 면의 불투명도는 **92% 이상.** 실측(뒤 덩어리를 글자색과 같은 최악 바탕으로 가득 채움): 본문 7:1은 r1·r5가 약 65%부터, r8(어두운 면)은 약 76%부터이고, 보조 글자 7:1은 r1 약 88%·r5 약 86%·r8 약 92%부터다. 92%면 세 벌 모두 본문·보조가 최악 바탕에서도 7:1을 넘는다. 이 값이면 비침은 8%라 「흐림이 보이는 면」은 글자 없는 오버레이 배경에서 주로 보인다.
  4. 블러 ≤ 20px, 글래스 위에 글래스를 겹치지 않는다.
  5. `prefers-reduced-transparency: reduce`·`prefers-contrast: more`에서 블러를 끄고 불투명 `card`로(견본에 넣었다).
  6. dashboard·public 원형 제외(C5 호환표 그대로).
- 대안(조건을 못 채울 때): C5 글래스를 그대로 쓰거나, 유리 대신 `card` 불투명 + 1px 안쪽 밝은 선 + X1 그레인으로 같은 인상을 낸다.
- 구현(견본): 뒤에 `ring`·`primary` 색 원 두 개와 사선 줄무늬를 깔고, 앞 면은 `backdrop-filter: blur(16px) saturate(1.3)` + `card` 92% 배경 + 1px 테두리.
- 성능: **가장 비싼 후보.** 블러는 스크롤·애니메이션마다 뒤 화면을 다시 합성한다. 고정 면 하나로 제한하고 작은 반경을 유지한다.
- 원형·레시피: brand·commerce(프리미엄 소비재) 오버레이. 견본에서 r5(청자)·r8(저녁)이 잘 어울린다.

## 질감 사이 공통

- 모두 이미지 파일 없이 SVG 데이터 URI(`feTurbulence`)·CSS 그라디언트·`mix-blend-mode`로 그린다. 글자 필터(`url(#id)`)를 쓰는 값은 `<svg><defs>` 한 벌이 문서에 있어야 한다 — `texture.tsx`에 숨은 `<svg>`를 함께 싣는 설계가 필요하다(훅만으로는 부족, 구현 때 결정).
- `mix-blend-mode`는 Chrome과 Safari가 조금 다르게 그린다(외부 글 「Grainy Gradients」 경고). 구현 때 두 엔진에서 확인한다.
- 모든 값이 정지 질감이라 동작 줄이기 설정과 무관하다. 간유리만 투명도 줄이기 설정을 따른다.
- 다크 면에서는 X1과 같이 곱하기 대신 스크린 + 반전을 쓴다(견본 r8).
